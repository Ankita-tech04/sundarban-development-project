# 🌿 Sundarban Development Web Platform

A full-stack web application developed using **Python & Django** to support sustainable regional development, environmental awareness, and community initiatives in the Sundarban delta region.

🌐 **Live Deployed Application:** [sundarbandevbyankita.pythonanywhere.com](https://sundarbandevbyankita.pythonanywhere.com/)

---

## 📌 Project Overview
The Sundarban region is an ecologically sensitive UNESCO World Heritage site requiring ongoing conservation and community development. This web platform serves as an interactive portal to highlight regional initiatives, manage media resources, and facilitate public awareness.

---

## 🛠️ Tech Stack & Architecture
- **Backend Framework:** Django (Python 3)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **App Module:** `fiemapp` (Django Application)
- **Database:** SQLite / Relational DB
- **Deployment Platform:** PythonAnywhere (WSGI Production Web Server)
- **Version Control:** Git & GitHub

---

## ✨ Key Features
- **Dynamic Content & Views:** Modular Django architecture with model-driven templates.
- **Media & Asset Management:** Dedicated static and media pipelines for regional photo/document galleries.
- **Responsive Web Design:** Fully responsive layout accessible across desktop, tablet, and mobile browsers.
- **Live Production Deployment:** Hosted and running 24/7 on cloud infrastructure.

## ⚙️ How to Run Locally

### 1. Clone the repository
```bash
git clone https://github.com/Ankita-tech04/sundarban-development-project.git
cd sundarban-development-project
```

### 2. Set up virtual environment
```bash
python -m venv env
# On Windows:
env\Scripts\activate
# On Linux/macOS:
source env/bin/activate
```

### 3. Install dependencies & run migrations
```bash
pip install django
python manage.py migrate
```

### 4. Run the development server
```bash
python manage.py runserver
```
Visit `http://127.0.0.1:8000/` in your browser.
